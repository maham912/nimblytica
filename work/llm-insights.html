Narrative layer on a metrics model

Case note wrapping the live briefing demo. Python over a metrics table; an LLM can sit on the same contract later. No API key required for the live demo.

Situation

A dashboard answers “what is the number.” Standups still spend time turning that number into five sentences. That last step is a function over a metrics model, not a new report.

Constraint

Do not send a model the whole warehouse. Give it a small JSON slice: this department, this as-of, these four cards, the top unit, the new names. If the key is missing, still print something a human can check.

Build

  1. Same snapshot. workforce.fake.json — invented Northwind Health Ops, round figures, invented people including Alex Rivera.
  2. Contract. brief_workforce(snapshot, department) -> list[str] of length five: cut, vacancy, trend, overtime, next check.
  3. Fallback first. The page runs that function in JavaScript. No key required. A hosted model would receive the same slice and must return the same shape.

Result

A briefing you can regenerate with a slicer. Live: demo/llm.html. This note is new work for a public evidence page. It is not a republish of a client notebook.
