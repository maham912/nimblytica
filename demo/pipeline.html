People-analytics export → Azure Data Factory → blob staging → Snowflake. The live board reads that grain. Power BI is optional on the same files.

    People-analytics export

    A scheduled extract. The cut the board is allowed to see — not a warehouse tour.

  2. 02

    Azure Data Factory

    The factory owns the clock. Copy, light type, fail in run history instead of a personal inbox.

  3. 03

    Blob staging

    Latest file wins. BI and the board never open the live system of record.

  4. 04

    Snowflake

    The warehouse the live board and, if you want it, Power BI both read. Same as-of.
